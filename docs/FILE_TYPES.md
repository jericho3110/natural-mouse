# File types

Every kind of file in this repository, and in a working copy of it, and
why it exists.

## Committed (in git)

| File / type | Example | Why it exists |
| --- | --- | --- |
| `.py` | `src/natural_mouse/path/bezier.py` | the code: the library (`src/natural_mouse/`), the apps (`src/gui/`, `src/testbench/`, `src/pathlab/`, `src/main.py`), tests, scripts, the example |
| `.md` | `README.md`, `docs/*.md` | documentation (Markdown: plain text that GitHub renders) |
| `.html` | `src/testbench/page.html` | the test bench's local web page |
| `.png` | `docs/images/pathlab.png` | the one picture used by the docs; generated by the path lab, shrunk for the README |
| `pyproject.toml` | — | the package's metadata (name, version, dependencies, the `[dev]` extra, plugin entry points) and build system (setuptools ≥ 77, for `license = "MIT"`) |
| `ruff.toml` | — | the linter's rules (which checks, line length, per-file exceptions with reasons) |
| `.github/workflows/ci.yml` | — | GitHub Actions: runs the check gate on Windows for every push and pull request |
| `.github/dependabot.yml` | — | GitHub opens pull requests when a dependency or an action has an update |
| `LICENSE` | — | the MIT license text: what others may do with the code |
| `CHANGELOG.md` | — | what changed per version (Keep a Changelog, SemVer) |
| `.gitignore` | — | files git must never pick up (below) |
| `templates/.gitkeep` | — | an empty file that keeps the `templates/` folder in git (git doesn't track empty folders) while its contents stay ignored |
| `.clinerules` | — | a project map for AI coding assistants: the real file list and ground rules |

## Generated or personal (ignored, never committed)

| File / folder | Made by | Why it's ignored |
| --- | --- | --- |
| `venv/` | `python -m venv venv` | this computer's private Python and packages; big, and specific to this machine |
| `__pycache__/`, `*.pyc` | Python, on import | compiled bytecode; rebuilt automatically |
| `src/natural_mouse.egg-info/` | `pip install -e .` | install metadata (version, entry points) for the editable install |
| `.ruff_cache/` | `ruff check` | speeds up the next lint; safe to delete |
| `templates/*` (except `.gitkeep`) | you (`capture`, the GUI) | screenshots of *your* screen: may show personal content |
| `targets.json` | the GUI | your saved targets, pointing at your screenshots |
| `pathlab*.png` (outside `docs/images/`) | `python src/main.py pathlab` | regenerate any time with the same seed |
| `.env` | you, if ever | secrets; the security scan also refuses it if it's ever tracked |

The security scan (`scripts/security_scan.py`) checks the "never
committed" rules on every run, so a mistake in `.gitignore` is still
caught.
